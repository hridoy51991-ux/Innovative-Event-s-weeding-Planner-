
INNOVATIVE EVENT & WEDDING PLANNER — FREE WEBSITE STARTER

Included:
- index.html: responsive website
- assets/logo.jpg: your supplied logo
- manifest.json: basic PWA metadata

To preview:
Open index.html in a browser.

To publish for free:
1. Create a GitHub account at https://github.com/
2. Create a new public repository.
3. Upload all files and folders in this package.
4. In repository Settings > Pages, select Deploy from branch and choose main / root.
5. Wait for GitHub Pages to publish your site.

Notes:
- Booking form prepares a WhatsApp message; it does not store requests in private database.
- Replace portfolio sample panels with your own photos.
- Verify contact numbers and social links before publishing.
- This is a website/PWA starter, not a Play Store native app.
